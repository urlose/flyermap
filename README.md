# FlyerMap

Система для раздачи флаеров: приложение для работников (iPhone) + панель для админов (браузер).

## Части

| Папка | Что это | Где работает |
|---|---|---|
| `admin/` | Панель админа: работники, задания с зоной 15 мин пешком, живая карта, маршруты, отчёты PDF/Excel/GPX | GitHub Pages (собирается автоматически) |
| `worker/` | Приложение работника: регистрация, задания, запись маршрута в фоне (даже с заблокированным экраном), офлайн-очередь | iPhone через SideStore (или TestFlight) |
| сервер | База Supabase `flyertrack` (Франкфурт) | Supabase |

## Как это собирается

- Любой push в `admin/` → workflow **Admin panel** публикует панель на `https://<user>.github.io/flyermap/`.
- Любой push в `worker/` → workflow **iOS app** собирает `FlyerMap.ipa` на macOS-сервере GitHub и выкладывает её в **Releases**.

## Установка приложения на iPhone (бесплатно, без App Store)

1. Один раз установить SideStore по инструкции на https://sidestore.io (нужен компьютер только для первой настройки).
2. На iPhone открыть страницу Releases этого репозитория, скачать `FlyerMap.ipa`.
3. «Поделиться» → SideStore (или в SideStore: My Apps → «+» → выбрать файл).
4. При первом старте маршрута разрешить геопозицию.

Бесплатная подпись Apple ID действует 7 дней — SideStore продлевает её сам в фоне.



## Первый админ

Откройте панель, нажмите «Создать аккаунт» и подтвердите email. **Первый зарегистрированный становится админом.** Остальных админов приглашают во вкладке «Админы».
